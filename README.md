# Artificial Intelligence Labs

This repository contains lab exercises and practical implementations for the **BS Artificial Intelligence** degree program.

## 📂 Repository Structure

* `Lab 1 AI.ipynb` — Comprehensive revision of core Python concepts, data structures, control flow, and NumPy fundamentals.

## 🛠️ Topics Covered (Lab 01)

* **Python Fundamentals:** Dynamic typing, type casting, arithmetic variable swapping, operator precedence.
* **Control Structures:** Conditional logic (`if-elif-else`), loops, and menu-driven programs using Python 3.10+ `match-case`.
* **Functions & Parsing:** Vowel counting functions and string transformations (`camelCase` to `snake_case`).
* **Compound Data Types:** Operations on Lists, Tuples, Sets, and Dictionaries (word frequency counting).
* **NumPy Basics:** Multi-dimensional arrays, reshaping, and mathematical aggregations (`sum`, `mean`, `min`, `max`).
